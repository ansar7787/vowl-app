# Onboarding SVG Illustrations

Drop your 4 SVG illustrations directly into this folder (`assets/illustrations/`):

| Slide | Filename | Recommended Concept |
| :--- | :--- | :--- |
| **Slide 1** | `onboarding_speech.svg` | Hero Vowl character + microphone + soundwaves |
| **Slide 2** | `onboarding_camera.svg` | Smartphone scanning real-world object with focus brackets |
| **Slide 3** | `onboarding_buddy.svg` | Vowl mascot with accessory + milestone rewards / stickers |
| **Slide 4** | `onboarding_progress.svg` | World globe + global accent badges (or progress graph) |

### Dimensions:
- **Aspect Ratio**: Roughly `4:3` or `1:1` square.
- **Recommended Canvas Size**: `300 x 240` px or `400 x 300` px.
- **Format**: Standard `.svg` (vector format) or `.png` / `.webp`.
